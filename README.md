# ⏰ Cozy Productivity Alarm

A responsive productivity alarm clock built using **HTML, CSS, and JavaScript**.

## ✨ Features

- ⏰ Live digital clock
- 🔔 Set and clear alarms
- 🎵 Audio alarm notifications
- 📱 Responsive design
- 🖱️ Interactive clock animations
- 📐 Device orientation effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Future Improvements

- Multiple alarms
- Pomodoro timer
- Dark mode
- Nature sounds
- Save alarms with Local Storage
- Custom alarm labels
